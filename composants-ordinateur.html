🖥️ Les composants de l'ordinateur

📘 Présentation du cours

Un ordinateur est un appareil électronique composé de plusieurs éléments matériels appelés composants. Chaque composant possède une fonction particulière.

Cette page permet aux élèves d'observer les images, de reconnaître les composants et de comprendre leurs rôles.

⚙️ Les 12 principaux composants

Matériel informatique

1. Unité centrale

Elle contient plusieurs composants internes nécessaires au fonctionnement de l'ordinateur.

Périphérique de sortie

2. Écran

Il affiche les textes, les images, les vidéos et les résultats du travail.

Périphérique d'entrée

3. Clavier

Il permet de saisir des lettres, des chiffres, des symboles et des commandes.

Périphérique d'entrée

4. Souris

Elle permet de déplacer le pointeur, de cliquer et de sélectionner des éléments.

Composant interne

5. Carte mère

Elle relie les principaux composants internes et permet leur communication.

Traitement

6. Processeur (CPU)

Il exécute les instructions et effectue les opérations de traitement.

Mémoire

7. Mémoire RAM

Elle conserve temporairement les données utilisées par les programmes en cours.

Stockage

8. Disque dur / SSD

Il conserve les fichiers, les logiciels et le système d'exploitation.

Énergie électrique

9. Bloc d'alimentation

Il fournit aux composants l'énergie électrique adaptée à leur fonctionnement.

Refroidissement

10. Ventilateur

Il aide à évacuer la chaleur produite par certains composants.

Affichage graphique

11. Carte graphique

Elle traite les informations graphiques. Elle peut être intégrée ou indépendante.

Périphérique de sortie

12. Haut-parleurs

Ils permettent d'écouter les sons, la musique et les vidéos.

📷 Ajouter une image depuis le téléphone

Choisis un composant, puis sélectionne sa photo dans la galerie de ton téléphone.

Important : La photo choisie s'affiche temporairement dans cette page. Pour la conserver dans le site, place le fichier dans le dossier sary et modifie le chemin de l'image dans le code HTML.

📝 Activités des élèves

  1. Identifier cinq composants de l'ordinateur.
  2. Écrire le nom de chaque composant.
  3. Expliquer le rôle de trois composants.
  4. Classer le clavier, la souris, l'écran et les haut-parleurs en périphériques d'entrée ou de sortie.
  5. Expliquer la différence entre la RAM et le disque dur.

✅ À retenir

Chaque composant a un rôle précis. La RAM est une mémoire temporaire, tandis que le disque dur ou le SSD conserve les fichiers durablement.
