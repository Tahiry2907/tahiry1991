💻 Les nombres binaires

📘 Définition

Le système binaire est un système de numération qui utilise seulement deux chiffres : 0 et 1.

🎨 Code couleur

1 = ON (allumé)
0 = OFF (éteint)

1 0 1 0

🧮 Exemple de conversion

Convertir 1010 en décimal :

1×2³ + 0×2² + 1×2¹ + 0×2⁰
= 8 + 0 + 2 + 0 = 10
