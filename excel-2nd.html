🔐 Excel Sécurisé - Projet Notes

👨‍🏫 Objectif : Gestion des notes avec une séparation entre la zone élève et la zone professeur.

💡 Projet pédagogique :

L'élève peut saisir ses notes dans les cellules jaunes. Le professeur peut ensuite utiliser les formules Excel pour calculer les moyennes et déterminer les résultats.

📐 Formules à utiliser

=MOYENNE(B2:D2)

👨‍🏫 Zone professeur :

Le professeur peut protéger les cellules contenant les formules afin d'éviter leur modification accidentelle.

Exemple :

=MOYENNE(B2:D2)
=SI(E2>=10;"Admis";"Échec")
⚠️ Sécurité :

La fonction contenteditable permet seulement de modifier les cellules dans le navigateur. Ce n'est pas une véritable protection informatique.

Pour une véritable sécurité en ligne, il faudra utiliser PHP, une connexion sécurisée, des sessions, des rôles Élève / Professeur et une base de données.
