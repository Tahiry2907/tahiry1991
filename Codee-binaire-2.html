Découvrir le Code Binaire 🤖

La langue secrète des ordinateurs

1. Qu'est-ce que le code binaire ?

Un ordinateur est une machine électronique. Pour fonctionner, il utilise des millions de petits interrupteurs. Ces interrupteurs ne peuvent avoir que deux états :

💡 Off 0

Le courant ne passe pas

💡 On 1

Le courant passe

Chaque 0 ou 1 est appelé un bit (Binary Digit).

2. Comment l'ordinateur compte-t-il ?

En combinant 8 bits (un octet), l'ordinateur peut créer 256 combinaisons différentes pour représenter des nombres, des lettres ou des couleurs.

0 1 0 0 0 0 0 1

En binaire, cette suite de 8 bits représente la lettre "A" !
