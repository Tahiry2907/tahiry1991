📌 1. Introduction

Un système informatique est constitué de plusieurs éléments qui travaillent ensemble pour permettre à l'utilisateur de saisir, traiter, stocker, afficher et transmettre des informations.

Les composants de l'informatique peuvent être classés en plusieurs grandes catégories :

  • 🖥️ Le matériel informatique (Hardware)
  • 💿 Les logiciels (Software)
  • ⌨️ Les périphériques d'entrée
  • 🖨️ Les périphériques de sortie
  • 💾 Les dispositifs de stockage
  • 🌐 Les équipements réseau
💡 À retenir : Un ordinateur fonctionne grâce à la collaboration entre le matériel et les logiciels.

🖥️ 2. Le matériel informatique — Hardware

Le hardware désigne l'ensemble des éléments physiques d'un système informatique.

Ce sont les composants que l'on peut généralement toucher ou manipuler physiquement.

Exemples :

  • Carte mère
  • Processeur
  • Mémoire RAM
  • Disque dur
  • SSD
  • Carte graphique
  • Alimentation
  • Écran
  • Clavier
  • Souris
  • Imprimante

🔌 3. La carte mère

La carte mère est la principale carte électronique de l'ordinateur.

Elle permet aux différents composants de communiquer entre eux.

Elle peut accueillir notamment :

  • 🧠 Le processeur
  • 💾 La mémoire RAM
  • 🎮 La carte graphique
  • 💽 Des dispositifs de stockage
  • 🔌 Des connecteurs et ports
  • 🌐 Des composants réseau
🔑 À retenir : La carte mère joue un rôle central dans la communication entre les composants.

🧠 4. Le processeur — CPU

Le CPU signifie Central Processing Unit.

En français, on l'appelle généralement processeur.

Il exécute les instructions des programmes et réalise de nombreux calculs nécessaires au fonctionnement du système.

Principales fonctions :

  • Lire les instructions.
  • Effectuer des calculs.
  • Traiter les données.
  • Exécuter les programmes.
CPU ↓ Lit les instructions ↓ Traite les données ↓ Effectue les opérations ↓ Produit des résultats

💾 5. La mémoire RAM

La RAM signifie Random Access Memory.

Elle sert principalement de mémoire de travail pour les programmes et les données actuellement utilisés par l'ordinateur.

Exemple :

Lorsque plusieurs applications sont ouvertes, elles utilisent une partie de la mémoire RAM.

⚠️ La RAM est une mémoire volatile : les informations qu'elle contient ne sont généralement pas conservées après l'arrêt de l'ordinateur.

💽 6. Les dispositifs de stockage

Les dispositifs de stockage permettent de conserver les données et les fichiers.

Principaux dispositifs :

  • 💽 HDD — disque dur
  • ⚡ SSD
  • 🔑 Clé USB
  • 💳 Carte mémoire
  • 💿 CD/DVD

💽 7. HDD — Disque dur

Le HDD est un dispositif de stockage utilisant notamment des éléments mécaniques pour enregistrer les données.

Il peut servir à conserver des documents, images, vidéos, logiciels et autres fichiers.

⚡ 8. SSD

Le SSD est un dispositif de stockage utilisant de la mémoire flash.

Il ne fonctionne pas comme un HDD classique avec un disque magnétique en rotation.

💡 Dans de nombreux ordinateurs modernes, le SSD est utilisé pour accélérer le démarrage du système et l'ouverture des applications.

🎮 9. La carte graphique — GPU

Le GPU est un composant spécialisé dans le traitement et le calcul de données graphiques.

Il peut être utilisé pour :

  • Afficher les images.
  • Traiter les graphiques 2D et 3D.
  • Faire fonctionner certains jeux.
  • Accélérer certains traitements graphiques.
  • Participer à certains calculs spécialisés.

🔋 10. L'alimentation

L'alimentation électrique fournit l'énergie nécessaire aux différents composants de l'ordinateur.

Dans un ordinateur de bureau, elle transforme et distribue l'énergie électrique adaptée aux composants.

❄️ 11. Le système de refroidissement

Les composants électroniques produisent de la chaleur lorsqu'ils fonctionnent.

Le système de refroidissement permet de maintenir une température adaptée au fonctionnement de l'ordinateur.

Exemples :

  • Ventilateur
  • Radiateur
  • Pâte thermique
  • Systèmes de refroidissement spécialisés

⌨️ 12. Les périphériques d'entrée

Un périphérique d'entrée permet à l'utilisateur ou à un autre système de transmettre des informations vers l'ordinateur.

Exemples :

  • ⌨️ Clavier
  • 🖱️ Souris
  • 🎤 Microphone
  • 📷 Webcam
  • 📠 Scanner
  • 🎮 Manette

🖨️ 13. Les périphériques de sortie

Un périphérique de sortie permet à l'ordinateur de transmettre des informations vers l'utilisateur.

Exemples :

  • 🖥️ Écran
  • 🖨️ Imprimante
  • 🔊 Haut-parleurs
  • 🎧 Casque audio
  • 📽️ Projecteur

🔄 14. Périphériques d'entrée et de sortie

Certains périphériques peuvent à la fois recevoir et transmettre des informations.

  • 📱 Écran tactile
  • 💾 Clé USB
  • 🌐 Carte réseau
  • 💽 Certains dispositifs de stockage

🌐 15. Les composants réseau

Les équipements réseau permettent aux appareils de communiquer entre eux et d'accéder à des ressources partagées ou à Internet.

Exemples :

  • 📡 Routeur
  • 🔀 Switch
  • 🌐 Carte réseau
  • 📶 Point d'accès Wi-Fi
  • 🔌 Câble réseau Ethernet

💿 16. Les logiciels — Software

Le software désigne les programmes et logiciels utilisés par l'ordinateur.

On peut distinguer :

  • 🖥️ Systèmes d'exploitation
  • 📄 Logiciels bureautiques
  • 🌐 Navigateurs Web
  • 🎨 Logiciels graphiques
  • 💻 Logiciels de programmation
  • 🛡️ Logiciels de sécurité

🖥️ 17. Le système d'exploitation

Le système d'exploitation est le logiciel principal qui permet de gérer les ressources de l'ordinateur et de fournir un environnement permettant d'exécuter des applications.

Exemples :

  • Windows
  • Linux
  • Android
  • macOS
  • iOS

🧩 18. Schéma général d'un système informatique

UTILISATEUR ↓ PÉRIPHÉRIQUES D'ENTRÉE ↓ TRAITEMENT ↓ CPU + RAM ↓ STOCKAGE ↓ PÉRIPHÉRIQUES DE SORTIE ↓ UTILISATEUR

📝 20. Exercices

Exercice 1 : Définir les termes suivants :

  1. Hardware
  2. Software
  3. CPU
  4. RAM
  5. SSD
Correction :

Hardware : ensemble des composants physiques.

Software : ensemble des logiciels et programmes.

CPU : processeur qui exécute les instructions.

RAM : mémoire utilisée principalement pour le travail temporaire du système et des programmes.

SSD : dispositif de stockage utilisant de la mémoire flash.

Exercice 2 : Classez les éléments suivants dans les catégories « Entrée », « Sortie », « Stockage » ou « Traitement » :

Clavier — Écran — CPU — Souris — SSD — Imprimante — RAM — Microphone

Correction :

⌨️ Entrée : Clavier, Souris, Microphone

🖥️ Sortie : Écran, Imprimante

💾 Stockage : SSD

🧠 Traitement / mémoire de travail : CPU, RAM

📚 22. Résumé de la leçon

À retenir :

🧩 Un système informatique est composé de plusieurs éléments.

🖥️ Le hardware représente le matériel.

💿 Le software représente les logiciels.

🧠 Le CPU traite les instructions.

💾 La RAM sert principalement de mémoire de travail.

💽 Le HDD et le SSD servent au stockage.

⌨️ Les périphériques d'entrée permettent de transmettre des informations vers l'ordinateur.

🖥️ Les périphériques de sortie permettent de recevoir les résultats produits par l'ordinateur.

🔌 La carte mère permet aux différents composants de communiquer.
