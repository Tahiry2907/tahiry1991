ÉPREUVE 2 — PRATIQUE /20

PARTIE A — Python /10

Écrire un programme Python qui demande les notes de trois matières, calcule la moyenne et affiche :

  • « Admis » si la moyenne est supérieure ou égale à 10 ;
  • « À renforcer » si la moyenne est inférieure à 10.

Le programme doit également afficher la moyenne obtenue.

PARTIE B — Web /10

Créer une page Web intitulée :

« Mon projet informatique »

La page doit contenir :

  • un en-tête ;
  • un menu de navigation ;
  • un titre principal ;
  • deux paragraphes ;
  • une liste ;
  • une image ;
  • un formulaire simple ;
  • un pied de page.

Utiliser HTML et CSS.

🔑 CORRIGÉ TERMINALE

Python :
input() permet de recevoir une donnée saisie par l'utilisateur.
print() permet d'afficher une information.

Réseau :
Une adresse IP identifie une interface sur un réseau IP. Une adresse MAC identifie une interface réseau au niveau matériel.

Base de données :
Une table organise les données. Un champ représente une propriété. Un enregistrement représente une ligne de données.

Web :
HTML structure la page, CSS définit sa présentation, JavaScript ajoute de l'interactivité et PHP permet notamment de traiter des données côté serveur.
