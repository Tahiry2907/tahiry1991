📘 Les éléments qui composent l'ordinateur

Un ordinateur est constitué de plusieurs éléments qui travaillent ensemble pour permettre à l'utilisateur de saisir, traiter, stocker et afficher des informations.

🎯 Objectif du cours : Identifier les principaux composants d'un ordinateur et comprendre leur rôle.

🖥️ Les éléments de base

🖥️

Écran / Moniteur

Permet d'afficher les informations et les résultats.

🖥️

Unité centrale

Contient plusieurs composants essentiels au fonctionnement de l'ordinateur.

⌨️

Clavier

Permet de saisir des textes, nombres et commandes.

🖱️

Souris

Permet de déplacer le pointeur et d'effectuer différentes commandes.

🔌 Autres périphériques

  • 🔊 Les enceintes
  • 🖨️ L'imprimante
  • 📄 Le scanner
  • 🌐 Le modem
  • 📷 La webcam

Le moniteur permet de visualiser les résultats des actions effectuées sur l'ordinateur.

Les principaux types d'écrans

  • Tube cathodique (CRT)
  • Écran plat (LCD)
  • LED
📏 Taille de l'écran : La dimension d'un écran est généralement déterminée par la longueur de sa diagonale et exprimée en pouces.

🖱️ La souris

La souris est un périphérique de pointage. Elle permet de déplacer le pointeur affiché à l'écran et d'effectuer différentes commandes.

🔘 Les boutons de la souris

  • Clic gauche : sélectionner et ouvrir.
  • Clic droit : afficher un menu contextuel.
  • Molette : faire défiler une page.
⚠️ À retenir : La souris permet principalement de contrôler le pointeur.

⌨️ Le clavier

Le clavier permet la saisie des informations en direction de l'ordinateur.

🔘 Les touches de base

  • Entrée / Enter
  • Espace / Space
  • Échap / Esc
  • Suppr / Delete
  • Retour arrière / Backspace
  • Caps Lock
  • Shift

⌨️ Comment manipuler le clavier ?

Pour apprendre à taper efficacement, il faut placer correctement les mains sur le clavier et s'entraîner régulièrement à utiliser les dix doigts.

💡 Conseil : L'entraînement régulier améliore la vitesse et la précision de frappe.

🌍 Types de clavier

  • AZERTY
  • QWERTY
  • Autres dispositions

🖥️ L'unité centrale

L'unité centrale, souvent appelée boîtier, contient plusieurs composants essentiels au fonctionnement de l'ordinateur.

🧠

Processeur (CPU)

Il exécute les instructions et effectue les calculs.

🧩

Carte mère

Elle permet aux différents composants de communiquer entre eux.

💾

Disque dur / SSD

Il permet de stocker les fichiers et les programmes.

🧠

Mémoire RAM

Elle conserve temporairement les données utilisées par les programmes.

⚠️ À retenir : L'unité centrale n'est pas seulement le processeur. Elle contient plusieurs composants.
