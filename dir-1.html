💻 CMD - Commande DIR Complète

📌 Définition

dir est une commande qui affiche tous les fichiers et dossiers d’un répertoire. Elle peut être combinée avec plusieurs options pour filtrer, trier ou sauvegarder les résultats.

📂 Fampiasana Fototra

dir

Afficher fichiers et dossiers dans le dossier courant.

dir C:\Users

Afficher fichiers dans un dossier spécifique.

dir *.txt

Afficher uniquement les fichiers .txt

⚙ Options Avancées

  • /p : pause après chaque page
  • /w : format compact
  • /a : inclure fichiers cachés et system
  • /o:n : trier par nom
  • /s : inclure sous-dossiers
  • /b : format minimal
  • /q : montrer propriétaire
  • /t:c : afficher date/heure de création

💾 Redirection

dir > liste.txt : sauvegarder résultat dans fichier
dir /s > tous_les_fichiers.txt : inclure sous-dossiers
