🎨 RGB 🔢 Binaire 🖌️ Color Picker ✏️ Exercice

🎨 1️⃣ Qu'est-ce qu'une couleur numérique ? 1️⃣ Inona ny loko numérique ?

Une couleur affichée sur un écran est généralement composée de trois composantes principales : Rouge (Red), Vert (Green) et Bleu (Blue).

On appelle ce système RGB ou RVB en français.

Ny loko asehon'ny écran dia matetika ahitana composantes telo : Rouge, Vert ary Bleu.

Antsoina hoe RGB izany système izany.

💡 RGB = Red + Green + Blue RGB = Rouge + Vert + Bleu

🌈 2️⃣ Le système RGB 2️⃣ Ny système RGB

Chaque composante RGB possède généralement une valeur comprise entre 0 et 255.

Cela signifie qu'une couleur possède trois valeurs : R, G et B.

Ny composante RGB tsirairay dia manana valeur eo anelanelan'ny 0 sy 255.

Noho izany dia misy valeurs telo : R, G ary B.

Couleur RGB Binaire
🔴 Rouge 255, 0, 0 11111111 00000000 00000000
🟢 Vert 0, 255, 0 00000000 11111111 00000000
🔵 Bleu 0, 0, 255 00000000 00000000 11111111
⚫ Noir 0, 0, 0 00000000 00000000 00000000
⚪ Blanc 255, 255, 255 11111111 11111111 11111111
🟡 Jaune 255, 255, 0 11111111 11111111 00000000
🟣 Magenta 255, 0, 255 11111111 00000000 11111111

🔢 3️⃣ Pourquoi 8 bits par couleur ? 3️⃣ Nahoana no bits 8 isaky ny couleur ?

Une composante RGB utilise généralement 8 bits.

Avec 8 bits, on peut représenter :

00000000 → 0
11111111 → 255

Il existe donc 256 valeurs possibles pour chaque composante.

Ny composante RGB iray dia mampiasa bits 8 matetika.

00000000 → 0
11111111 → 255

Noho izany dia misy valeurs 256 azo ampiasaina amin'ny composante iray.

8 bits → 256 valeurs → 0 à 255

🖥️ 4️⃣ Pixel et couleur 4️⃣ Pixel sy couleur

Un écran est composé de nombreux petits points appelés pixels.

Chaque pixel peut recevoir une couleur déterminée par les valeurs RGB.

Ny écran dia misy teboka madinika maro antsoina hoe pixels.

Ny pixel tsirairay dia afaka manana couleur iray voafaritra amin'ny valeurs RGB.

💡 Un pixel RGB utilise généralement 24 bits : 8 bits Rouge + 8 bits Vert + 8 bits Bleu. Ny pixel RGB iray dia mampiasa bits 24 matetika : 8 bits Rouge + 8 bits Vert + 8 bits Bleu.
R = 11111111
G = 00000000
B = 00000000

Total = 24 bits

🔷 7️⃣ RGB et code HEX 7️⃣ RGB sy code HEX

Les couleurs peuvent également être écrites avec le système hexadécimal.

Par exemple :

Rouge
RGB : (255, 0, 0)
HEX : #FF0000

Le code HEX utilise 6 caractères : deux pour Rouge, deux pour Vert et deux pour Bleu.

Azo soratana amin'ny système hexadécimal ihany koa ny couleurs.

Rouge
RGB : (255, 0, 0)
HEX : #FF0000

Ny code HEX dia mampiasa caractères 6 : roa ho an'ny Rouge, roa ho an'ny Vert ary roa ho an'ny Bleu.

⚠️ RGB et HEX sont deux façons différentes de représenter la même couleur. RGB sy HEX dia fomba roa samihafa hanehoana ny couleur iray ihany.
