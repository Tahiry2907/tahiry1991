Guides disponibles

🔌
MATÉRIEL

1. L’ordinateur ne démarre pas

Aucun voyant ou aucun signe de démarrage.

  1. Vérifiez la prise électrique et le câble d’alimentation.
  2. Sur un portable, vérifiez le chargeur et le voyant de charge.
  3. Débranchez les périphériques USB non nécessaires puis réessayez.
  4. Si aucun voyant ne s’allume, faites contrôler l’alimentation ou la carte mère.
🖥️
MATÉRIEL

2. Écran noir

L’ordinateur semble fonctionner, mais rien ne s’affiche.

  1. Vérifiez que l’écran est allumé et que son câble est bien connecté.
  2. Choisissez la bonne source vidéo : HDMI, VGA ou DisplayPort.
  3. Sur un portable, essayez la touche de fonction d’affichage indiquée sur le clavier.
  4. Si le problème persiste, faites vérifier la RAM et la carte graphique par une personne compétente.
💽
STOCKAGE

3. Disque dur non détecté

Le disque fonctionne sur un autre PC mais n’est pas reconnu ici.

  1. Entrez dans le BIOS/UEFI et cherchez les informations de stockage.
  2. Éteignez le PC et débranchez-le avant de vérifier les câbles SATA et d’alimentation.
  3. Essayez un autre port SATA et un autre câble compatibles si vous savez le faire.
  4. Si le disque n’apparaît toujours pas, vérifiez les réglages du contrôleur et la compatibilité.
  5. Ne formatez pas le disque si vous souhaitez récupérer des fichiers.
🧠
MÉMOIRE

4. Problème de RAM

Bips au démarrage, redémarrages ou écran noir.

  1. Éteignez l’ordinateur, débranchez-le et attendez l’arrêt complet.
  2. Si vous savez ouvrir le boîtier en sécurité, vérifiez que la RAM est correctement installée.
  3. Testez une barrette à la fois uniquement si vous maîtrisez cette opération.
  4. Consultez le manuel pour interpréter les bips.
⚙️
BIOS / UEFI

5. Accéder au BIOS ou Boot Menu

Utilisez la touche adaptée à la marque et au modèle.

  1. Éteignez complètement le PC, puis rallumez-le.
  2. Dès l’allumage, appuyez plusieurs fois sur la touche indiquée pour votre modèle.
  3. Si la touche ne fonctionne pas, consultez le manuel.
  4. Ne modifiez pas les réglages sans comprendre les conséquences.

Touches souvent utilisées :

  • HP : Esc puis F9 (Boot Menu) ou F10 (BIOS)
  • Dell : F12 (Boot Menu) ou F2 (BIOS)
  • Lenovo : F12 ou bouton Novo selon le modèle ; F1/F2 sur certains modèles
  • Acer : F12 (Boot Menu) ou F2 (BIOS)
  • ASUS : Esc (Boot Menu) ou F2 (BIOS)

Ces touches sont indicatives : elles peuvent varier selon le modèle.

💿
WINDOWS

6. Disque absent pendant l’installation Windows

L’installateur Windows ne montre aucun disque disponible.

  1. Vérifiez d’abord si le SSD/HDD apparaît dans le BIOS/UEFI.
  2. S’il est absent du BIOS, vérifiez le branchement, le port et la compatibilité.
  3. S’il est détecté dans le BIOS mais absent de l’installateur, vérifiez le pilote de stockage requis.
  4. Certains PC utilisent Intel RST/VMD ou un mode RAID.
  5. Ne supprimez aucune partition.
🚫
DÉMARRAGE

7. No Bootable Device

Le PC ne trouve pas de système à démarrer.

  1. Vérifiez si le disque est reconnu dans le BIOS/UEFI.
  2. Vérifiez l’ordre de démarrage.
  3. Si Windows est installé mais ne démarre pas, utilisez les options de réparation.
  4. Si le disque fait des bruits inhabituels, protégez les données.
🐢
WINDOWS

8. Windows est lent

Le démarrage ou l’ouverture des logiciels prend trop de temps.

  1. Redémarrez l’ordinateur et vérifiez les mises à jour.
  2. Utilisez le Gestionnaire des tâches.
  3. Désinstallez uniquement les logiciels inutiles.
  4. Vérifiez l’espace libre et lancez une analyse de sécurité.
  5. Sauvegardez les données avant toute réinitialisation.
🌐
RÉSEAU

9. Internet ne fonctionne pas

Le Wi-Fi ou la connexion réseau ne fonctionne plus.

  1. Vérifiez si les autres appareils ont accès à Internet.
  2. Vérifiez le Wi-Fi, le mode avion et les câbles réseau.
  3. Redémarrez le routeur si vous êtes autorisé à le faire.
  4. Vérifiez le pilote réseau et contactez le fournisseur d’accès.
💻
HP

10. Dépannage des ordinateurs HP

Accès au menu de démarrage et aux diagnostics.

  1. Au démarrage, appuyez plusieurs fois sur Esc.
  2. F9 ouvre souvent le Boot Device Options ; F10 ouvre souvent le BIOS Setup.
  3. Selon le modèle, lancez les diagnostics matériels.
  4. Vérifiez le manuel officiel de votre modèle.
💻
DELL

11. Dépannage des ordinateurs Dell

Vérifier le disque, le démarrage et les diagnostics.

  1. F12 ouvre souvent le menu de démarrage et les outils de diagnostic.
  2. F2 permet souvent d’ouvrir les paramètres BIOS.
  3. Exécutez les diagnostics et notez les codes d’erreur.
  4. Confirmez les touches exactes.
💻
LENOVO

12. Dépannage des ordinateurs Lenovo

Accès au BIOS ou au menu de démarrage selon le modèle.

  1. Selon le modèle, F1 ou F2 peut ouvrir les paramètres BIOS.
  2. F12 ouvre souvent le menu de démarrage.
  3. Certains modèles disposent d’un bouton Novo dédié.
  4. Vérifiez la procédure exacte dans le guide Lenovo.
💻
ACER

13. Dépannage des ordinateurs Acer

Vérifier le BIOS et l’ordre de démarrage.

  1. F2 ouvre souvent le BIOS.
  2. F12 peut ouvrir le menu de démarrage, si cette option est activée.
  3. Si F12 ne fonctionne pas, vérifiez le manuel.
💻
ASUS

14. Dépannage des ordinateurs ASUS

Accéder au BIOS ou sélectionner un périphérique de démarrage.

  1. F2 ouvre souvent le BIOS.
  2. Esc peut ouvrir le menu de démarrage sur certains modèles.
  3. Consultez la documentation ASUS si les touches ne fonctionnent pas.
